php-epub improvement backlog — 2026-11-01 (round 6)¶

Discovery-only audit of src/, bin/, scripts/, docs/, tests/ and .github/workflows/ at ed9f611 (feat/round5-backlog: the round-5 implementation, not yet merged into main). No source changes were made while compiling this list.

Gate results (fresh dependencies, composer update)¶

Gate Result

The 16 uncovered lines are the symlink-only branches of FileSystemHelper, ZipHandler and EpubFile::copyTree(), plus the four round-5 paths in SWEEP-03. The epubcheck group was not run locally (no EPUBCHECK_JAR).

Besides the gates and the code review, behavioural probes were run against the seven real-world fixtures. They round-tripped metadata, the TOC, landmarks and the page list. They also covered EPUB 2 → 3 upgrades, merges, compress(), moves, deletes, the exports, the Kindle profile, both PDF engines and the CLI. Those probes turned up BUG-01 to BUG-04, CONV-01, FEAT-01 and SWEEP-01/02.

The target was 30. Only 27 items held up after checking, and the list was not padded. No security vulnerabilities were found. ZIP extraction and directory import, PathResolver, XmlParser, the stream buffering cap, Dompdf's sandbox options, Calibre's shell-free process call and the pinned font downloads were re-checked. SEC-01 is hardening. Theme 1 (BUG-01 to BUG-04, UX-02), Theme 2 (CONV-01, CONV-02, CONV-03, TEST-02) and Theme 3 (SWEEP-01, FEAT-01, FEAT-02, FEAT-03) have been fully completed.

Execution instructions¶

  • One branch and one PR per theme (see Themes below); stack PRs that touch the same files.
  • Write the failing test first. Build hostile EPUBs inside the test (tests/Support/EpubBuilder) rather than committing binary fixtures.
  • Before every push run the gates against fresh dependencies, as CI does (composer update, composer quality, then git checkout composer.lock), and check each exit code.
  • Tick the box here in the same PR that fixes an item. Delete docs/improvement-audit/ once every item is done or explicitly declined (list declined items in that PR's description).
